# Ubuntu fonts

Self-hosted, unmodified WOFF2 files from Canonical's Ubuntu assets service.
The Latin builds cover the site's English text; characters not present in these
fonts use the system fallback stack, including Chinese text.

| Local file | Upstream file |
|---|---|
| `ubuntu-latin.woff2` | https://assets.ubuntu.com/v1/f1ea362b-Ubuntu%5Bwdth,wght%5D-latin-v0.896a.woff2 |
| `ubuntu-latin-italic.woff2` | https://assets.ubuntu.com/v1/90b59210-Ubuntu-Italic%5Bwdth,wght%5D-latin-v0.896a.woff2 |
| `ubuntu-mono-latin.woff2` | https://assets.ubuntu.com/v1/d5fc1819-UbuntuMono%5Bwght%5D-latin-v0.869.woff2 |

Source declarations: https://github.com/canonical/vanilla-framework/blob/main/scss/_base_fontfaces.scss

The original copyright notices are embedded in the unmodified font metadata.
